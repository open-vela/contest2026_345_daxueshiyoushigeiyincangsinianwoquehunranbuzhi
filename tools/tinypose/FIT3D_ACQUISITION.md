# Fit3D 获取与当前项目适配说明

核对日期：2026-10-24。个人手机视频采集当前记为待完成，不要求立即开展。

## 获取入口

1. 阅读 [官方条款](https://fit3d.imar.ro/legal)，确认实际使用目的在许可范围内。
2. 打开 [官方下载页](https://fit3d.imar.ro/download)。未登录页面提示需要有效账号。
3. 通过页面的 Log in 进入登录页，按网站提供的注册/账号获取流程操作；如页面没有开放注册，
   联系官网作者申请访问，不猜测审批时长、不使用第三方共享账号或绕过访问要求。
4. 取得有效账号和许可后，下载 Training Set；页面标示约18GB。Testing Set 约1.4GB，
   是否含可用真值需检查归档，不能把测试资源或 submission template 当训练数据。
5. 将原始压缩包放到 `.secrets/datasets/fit3d/raw/`，保留 README、许可、目录结构、
   相机参数、关键点和 repetition segmentation 等标注，不只单独拷出视频。

下载入口已通过匿名只读 HTTP GET 核对：有 Log in、Training Set 18GB、Testing Set 1.4GB。
本次没有创建账号、提交表单、接受许可或下载受限素材。

## 数据用途与范围

[数据页](https://fit3d.imar.ro/fit3d)列出多视角RGB视频、900×900、50fps、
运动类别和重复动作时间段。其参考论文明确讨论 squat 与 burpees：
[AIFit 原论文](https://fit3d.imar.ro/sites/default/files/public/pdf/Fieraru_2021_CVPR.pdf)。
实际文件名、动作覆盖和版本以获准下载的归档为准，不根据宣传页假设具体字段。

当前优先取 RGB 视频、动作类别、人物编号、相机编号、重复动作时间段。
3D人体网格、纹理和完整3D重建流程不是当前8点学生模型的必要输入。
如果归档只提供整体大包，则下载后再本地筛选，不假设支持按动作单独下载。

Fit3D 的25关节包含 Human3.6M 17关节，不能直接视为 COCO 17点。
可以先通过已有 MoveNet 教师生成 COCO 17点/当前8点伪标签，再人工修正。
若使用原生3D真值，需要检查关节定义、相机内外参、畸变和坐标系后投影为2D。
不能仅取前17项或将3D的X/Y直接当图像坐标。

同一个人物的所有动作和所有视角必须分到同一 split；不能把同一次动作的另一个相机
当作独立验证。官方隐藏测试集不用于调参；根据可用训练人物另行划分内部验证人物。

## 许可限制

官方免费许可允许的范围以 [legal](https://fit3d.imar.ro/legal) 为准，
明确排除商业用途，并禁止使用数据训练商业用途的方法/神经网络。
因此不能假设“免费能下载”就能进入产品训练，也不能通过教师伪标签消除原素材的限制。
决赛展示是否符合许可需结合比赛用途向数据方确认，本记录不替许可方作出批准。

询问是否允许训练及分发模型权重、公开演示，并保留书面回复。
本次未代用户发送邮件。
